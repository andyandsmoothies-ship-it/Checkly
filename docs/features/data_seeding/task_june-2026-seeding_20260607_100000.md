# Seeding completed audits for June 2026

This plan explains how we will seed exactly **1 completed audit** for each of the **20 current stores** in **June 2026**.

## 1. Flowchart of Data Insertion

```
[Fetch Stores & Auditors]
            |
            v
[For each Store (1 to 20)]
            |
            +---> [1. Create Submission (Completed between June 1 and June 6, 2026)]
            |
            +---> [2. Create 3 Section Scores (Opening, Daily, Closing)]
            |
            +---> [3. Create 7 Answers (Conform / Non-Conform)]
```

## 2. Selected Core Entities
We query the existing database to use correct, real values:
- **Template**: `Basic checklist` (ID: `d1c26713-d9fe-4550-bca2-7608f969eb1d`)
- **Auditors**: Choose randomly between existing auditors:
  - `Auditor 1` (`auditor1@checkly.local`, ID: `2630946e-8eb7-4836-ace8-33129ff7885b`)
  - `Auditor 2` (`auditor2@checkly.local`, ID: `88e81a53-2ed0-40b4-90c5-95c652466bfe`)
- **Stores**: All 20 current stores in the database.

## 3. Detailed Data Plan per Store

For each store $i$ (index 0 to 19):

### A. Submission
- **ID**: Random UUID
- **StoreId**: `store.id`
- **StoreName**: `store.name`
- **TemplateId**: `d1c26713-d9fe-4550-bca2-7608f969eb1d`
- **TemplateTitle**: `"Basic checklist"`
- **AuditorId**: Randomly select `auditor1` or `auditor2`
- **AuditorName**: Name of the selected auditor
- **AuditorEmail**: Email of the selected auditor
- **Status**: `"completed"`
- **ReviewStatus**: `"approved"`
- **TotalScore**: Random value between 75.0 and 98.0
- **Dates**:
  - `completed_at` = Random date between `2026-06-01` and `2026-06-06` (inclusive), at a random hour/minute
  - `created_at` = `completed_at` minus 1 hour
  - `started_at` = `completed_at` minus 45 minutes

### B. Submission Section Scores
Insert 3 section scores for the 3 sections of the template:
1. **Opening Tasks** (ID: `993033a8-2c36-4fad-8ff3-e7f5ba1b06b7`)
2. **Daily Operations** (ID: `28dd0b87-f9e9-4b37-ab91-30c18eec2863`)
3. **Closing Tasks** (ID: `87f4f487-809a-4e62-8047-cf35cb04a54a`)
- **Score**: Slightly adjusted from `total_score` (between `50.0` and `100.0`)

### C. Answers
Insert 7 answers corresponding to the 7 criteria in the `Basic checklist` template:
- **Daily Operations** Criteria:
  1. `77422a3f-2197-4b29-8d58-4635b89c2e26` (Log temperature readings)
  2. `9a1f4cb2-1b48-4de1-bcb1-274e64bcafb4` (Perform visual inspection)
- **Closing Tasks** Criteria:
  3. `3f9bd58b-cedb-45f2-968e-46d762fbf320` (Kiem tra cuoi ca ban hang)
- **Opening Tasks** Criteria:
  4. `7caf6994-e644-4402-b32a-bee7abbd27b1` (Brief team on objectives)
  5. `c826561b-a1a9-4c79-8641-020b764e3017` (Unlock and secure premises)
  6. `f3347f18-0c5f-41a0-a2f7-de7fe9705922` (Power on equipment)
  7. `fe090bdd-21a7-4915-a0a4-933c199f184a` (Check inventory levels)
- **Value**: `"conform"` for passing criteria, `"non_conform"` for failing criteria (matching the target score ratio).
