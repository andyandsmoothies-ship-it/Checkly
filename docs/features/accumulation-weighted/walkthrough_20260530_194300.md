## Decision Log

| Proposed Design | Implemented Design | Rationale |
|---|---|---|
| **Add isWeighted to ScoringInput** | Implemented `final bool isWeighted;` in `ScoringInput` defaulting to `false` in constructor. | Ensures backward compatibility with zero blast radius on existing callers. |
| **Map isWeighted in ScoringInputMapper** | Added `isWeighted` configuration mapping inside `ScoringInputMapper.fromTemplate()` method. | Closes the mapping gap for 'up' scoring direction (Shape B requirement). |
| **Dispatch switch split in ScoringEngine** | Modified the `accumulation` arm in `ScoringEngine.calculate()` to check `input.isWeighted` and route accordingly. | Allows clean, conditional dispatch without polluting the unweighted accumulation path. |
| **New WeightedAccumulationCalculator** | Created `WeightedAccumulationCalculator` incorporating `Σ(sectionEarned/sectionPossible × weight/totalWeight) × 100` math. | Completely isolates the new math engine in its own testable static service. |
