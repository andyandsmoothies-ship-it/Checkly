## Specification

### 1. `ListStores.cs` Query Parameters & Filtering
Add to query:
- `string? Province`
- `string? District`
- `string? ManagerName`

Filtering behavior in DB query:
- If `Province` is specified (not null or whitespace), filter stores where `Store.Address2.Province == Province` (exact match).
- If `District` is specified:
  - If `District` matches `"Unassigned"`, filter stores where `s.Address2.District == null || s.Address2.District == ""`.
  - Otherwise, filter stores where `Store.Address2.District == District`.
- If `ManagerName` is specified:
  Join or look up through assignments to find assigned managers whose name contains the search string (case-insensitive).
  Specifically: A store has `ProfileStoreAssignments` which links to a user profile. The manager can be either `store_manager` or `area_manager`. Search profile's full name.

### 2. `GetDistricts.cs` Endpoint
Create `GetDistricts.cs` inside `server/Features/Reference/` with:
- Query: `GetDistrictsQuery(string Province)`
- Returns: `List<string>` containing distinct sorted districts for active stores in that province.
- Filter out null and empty districts from the sorted list using `s.Address2.District != null && s.Address2.District != ""`.
- **Unassigned District Handling**: If there are any active stores in the requested province where `s.Address2.District` is null or empty (`s.Address2.District == null || s.Address2.District == ""`), append the value `"Unassigned"` to the returned list.

### 3. Route mapping
In `ReferenceEndpoints.cs`:
- `group.MapGet("/districts", ...)` maps to `GetDistricts.HandleAsync`.
