# Failure Report — BOD Analytics App Freeze on Card Click

## Input Lineage
- **Source**: `lib/features/analytics/widgets/bod_ap_bucket_detail_sheet.dart`
- **Log Key Line**: `[BOD] loadReport → notifyListeners()`
- **Flutter Exception**: `setState() or markNeedsBuild() called during build`

---

## Root Cause

**Pattern**: Widget Lifecycle Violation — `notifyListeners()` called synchronously during the Flutter build phase.

`BodApBucketDetailSheet.initState()` called `widget.manager.loadApDetails()` DIRECTLY without deferring to the post-frame callback. `loadApDetails()` sets `_isApDetailLoading = true` and immediately calls `notifyListeners()`. Flutter was still building the initial widget tree at that moment, so the `AnimatedBuilder` attempted to rebuild itself mid-build — an illegal operation.

```
[initState()] → [loadApDetails()] → [notifyListeners()] fired DURING build
                                           ↓
                                [AnimatedBuilder tries to rebuild]
                                           ↓
                      CRASH: "setState() called during build"
```

---

## Explicit Code Trace

**The bad code (before fix):**
```dart
// bod_ap_bucket_detail_sheet.dart — line 29
void initState() {
  super.initState();
  widget.manager.loadApDetails(widget.bucketName); // <-- no addPostFrameCallback!
}
```

**The correct pattern already in BodCategoryDetailSheet and BodStoreDetailSheet:**
```dart
void initState() {
  super.initState();
  WidgetsBinding.instance.addPostFrameCallback((_) {
    if (mounted) widget.manager.loadCategoryDetail(widget.categoryName);
  });
}
```

---

## Proposed Scope-Limited Fix

Wrap `loadApDetails()` in `addPostFrameCallback()` + `mounted` guard — identical to the 3 other sheets.

**Trade-offs:**
- Zero risk. This is the standard Flutter pattern for all async operations initiated on widget mount.
- The `mounted` guard prevents a memory leak if the sheet is closed before the frame renders.
- Very slight delay (1 frame = 16ms) before loading begins. This is imperceptible and shows the loading skeleton correctly.

---

## Fix Applied

**File**: `lib/features/analytics/widgets/bod_ap_bucket_detail_sheet.dart`

```diff
-    widget.manager.loadApDetails(widget.bucketName);
+    WidgetsBinding.instance.addPostFrameCallback((_) {
+      if (mounted) {
+        widget.manager.loadApDetails(widget.bucketName);
+      }
+    });
```
