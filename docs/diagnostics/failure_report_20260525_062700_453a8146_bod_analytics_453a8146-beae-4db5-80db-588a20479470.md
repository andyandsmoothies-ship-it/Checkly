# Failure Report: BOD Analytics Refresh 429 Crash

## Input Lineage
- **Source Input**: `c:\Users\HP\Documents\GitHub\Checkly\lib\features\analytics\manager\bod_analytics_manager.dart`

## Root Cause
When the `/analytics/bod/refresh` API endpoint returns a `429 Too Many Requests` (Rate limit exceeded), the `BodAnalyticsManager` attempts to display a warning toast to the user. It does this by retrieving the `InteractionManager` from the GetIt service locator (`GetIt.instance<InteractionManager>()`). However, `InteractionManager` was never registered in the global Dependency Injection configuration (`lib/locator.dart`). This caused GetIt to throw a `StateError` during the HTTP catch block, which immediately crashed the app's refresh cycle and left the layout hanging with no response.

## Explicit Code Trace (Premises + Proof)
1. **The Catch Block (`bod_analytics_manager.dart:115`)**:
   When the `Dio` client encounters a 429, the stringified error is caught:
   ```dart
   if (errStr.contains('429')) {
     _isLoading = false;
     GetIt.instance<InteractionManager>().showWarningToast('Rate limit exceeded...');
   }
   ```
2. **The Missing Registration (`locator.dart`)**:
   A search through `lib/locator.dart` (which handles all global singleton registrations) confirmed that `di.registerLazySingleton<InteractionManager>(...)` was completely missing. 

## Proposed Scope-Limited Fix
The fix is highly isolated and scoped to the DI configuration file.

* **Fix**: Inject `InteractionManager` into the `GetIt` container inside `lib/locator.dart`.
  ```dart
  import '_shared/services/interaction_manager.dart';
  // ...
  di.registerLazySingleton<InteractionManager>(() => InteractionManager());
  ```
* **Trade-offs / Pros & Cons**:
  * **Pros**: This correctly resolves the DI failure globally, allowing any manager across the application to trigger toasts via `InteractionManager` without throwing a `StateError`.
  * **Cons**: Instantiates an additional singleton at startup, though the memory overhead of `InteractionManager` is virtually zero.
