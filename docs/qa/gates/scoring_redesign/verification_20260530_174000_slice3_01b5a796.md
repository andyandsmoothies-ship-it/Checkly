## Adversarial Interrogation (Red Team Gate)

### 1. Concurrency Extreme (Race Conditions & Thundering Herds)
- *Question*: What happens when multiple database or API calls happen simultaneously?
- *Analysis*: SQLite DB calls in Flutter are processed in order on a native SQLite connection. `TemplateDao.upsertTemplates()` utilizes Drift batches (`_db.batch`), which execute within a single SQLite transaction, safeguarding atomic replacement.

### 2. Volume Extreme (Payload limits & OOM Crashes)
- *Question*: What happens when lists of templates, groups, or criteria grow by 10,000x?
- *Analysis*:
  - Drift queries on `cachedTemplates`, `cachedGroups`, and `cachedCriteria` all possess explicit memory-safety limits `..limit(500)` to guard against OOM on massive query outputs (preventing Gotcha #14).
  - In `TemplateDao.getTemplateTree()`, criteria pre-fetching utilizes a single SQL `IN` query on the retrieved group IDs. This avoids an recursive $N+1$ query loop in Dart memory, yielding high efficiency.

### 3. Dependency Extreme (Systemic Failure / Offline resilience)
- *Question*: What happens when network latency is high or offline?
- *Analysis*: The system is offline-first. `TemplateManager` fetches from local SQLite Drift first, emitting immediately. It then tries background API sync. If the network fails, it handles the exception gracefully, preserving the user's interactive cached view.

## Supportability & Tradeoffs (Crickett's Rule)

- **What does this code do?**
  It stores and synchronizes `categoryTag` at the Template level in SQLite (Drift) cache-first storage alongside `categoryTags` at Group and Criterion levels.
- **Why is it done this way?**
  By utilizing Drift database schemas with custom migration v32, we map the backend template model exactly to SQLite. Splitting group/criterion tags by commas resolves the lack of native array support in SQLite.
- **What are the tradeoffs?**
  Serializing arrays as comma-separated strings loses structured indexes, but keeps SQLite storage simple and lightweight without excessive helper tables.
