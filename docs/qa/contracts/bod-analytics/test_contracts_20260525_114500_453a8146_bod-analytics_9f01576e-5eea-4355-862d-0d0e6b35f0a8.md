## 1. Acceptance Criteria (Gherkin Format)

### Scenario 1: AP Bucket Normalization Flow
- **Given** a user is viewing the Board of Directors action plan aging report
- **When** the user selects an AP bucket with display name:
  - `"0-30 Days"`
  - `"31-60 Days"`
  - `"61-90 Days"`
  - `"90+ Days"`
- **Then** the manager normalized string matches:
  - `"0-30d"`
  - `"31-60d"`
  - `"61-90d"`
  - `"90d+"`
- **And** the `BodAnalyticsApiService` is invoked with the normalized string.

### Scenario 2: AP Bucket Normalization Concurrency Guard
- **Given** `loadApDetails` is currently active and loading
- **When** a second duplicate request to `loadApDetails` is triggered
- **Then** the second request is immediately discarded to prevent concurrent duplicate loading.

### Scenario 3: AP Details List Population Success
- **Given** the `BodAnalyticsApiService` successfully returns a list of `ApDetailEntry`
- **When** `loadApDetails` is called
- **Then** the manager's `apDetails` list matches the mock response
- **And** the loading state `isApDetailLoading` transitions to `false`
- **And** listeners are notified.

### Scenario 4: AP Details Error Path Recovery
- **Given** the `BodAnalyticsApiService` throws a Dio network error
- **When** `loadApDetails` is called
- **Then** the manager's `apDetails` list is reset to empty
- **And** the `error` state is populated with the error message
- **And** the loading state `isApDetailLoading` transitions to `false`.

### Scenario 5: Store BOD Summary Loading and Parsing
- **Given** the `BodAnalyticsApiService` successfully returns a valid `StoreBodSummary` response
- **When** `loadStoreDetail` is called with a store ID
- **Then** the manager's `storeDetail` is populated with the correct store name, recent audits, and category breakdown
- **And** `isStoreDetailLoading` transitions to `false`.

### Scenario 6: Category Detail Trimming and Loading
- **Given** the `BodAnalyticsApiService` successfully returns a list of `CategoryStoreEntry`
- **When** `loadCategoryDetail` is called with a category name containing leading/trailing whitespace like `"  Food Safety  "`
- **Then** the category name is trimmed to `"Food Safety"`
- **And** the api service is invoked with `"Food Safety"`
- **And** `categoryDetail` matches the mocked store entries.

### Scenario 7: Client-Side Auditor Productivity Filtering
- **Given** the `BodAnalyticsApiService` successfully returns multiple auditor productivity entries
- **When** `loadAuditorDetail` is called with a target auditor name
- **Then** the manager filters the returned list client-side to isolate the target auditor's productivity entry
- **And** populates `auditorDetail` with the isolated entry.
