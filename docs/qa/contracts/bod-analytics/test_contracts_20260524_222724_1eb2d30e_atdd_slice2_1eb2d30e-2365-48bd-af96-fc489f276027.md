# Physical Acceptance Test Contracts - Slice 2
## Topic: AP Drill-Down & Auditor Productivity

```
[HTTP CLIENT] ──GET /api/analytics/bod/ap/{bucket}──────► [BOD AP Controller] ──► [Open Action Plans]
[HTTP CLIENT] ──GET /api/analytics/auditors/productivity──► [Auditor Bias Engine] ──► [Auditor Calibration]
```

## Scenario 1: Retrieve Action Plan Details for a Specific Aging Bucket (TC-06)
*   **Given** there is an open Action Plan created 100 days ago (Bucket: `90d+`)
*   **And** there is an open Action Plan created 10 days ago (Bucket: `0-30d`)
*   **When** a user with `analytics:bod` capability requests `GET /api/analytics/bod/ap/90d+`
*   **Then** the response status is `200 OK`
*   **And** the response body contains a JSON array containing only the action plan from the `90d+` bucket
*   **And** each entry includes `{ id, criteriaLabel, storeName, managerName, ageInDays }`

## Scenario 2: Validation of Invalid Aging Bucket Input
*   **Given** a client is authenticated with proper credentials
*   **When** they request `GET /api/analytics/bod/ap/invalid_bucket_value`
*   **Then** the response status is `400 Bad Request`

## Scenario 3: Calibrate Auditor Bias Ratings (TC-11)
*   **Given** auditor submissions exist:
    *   Strict Auditor: avg score = `75.0%`
    *   Generous Auditor: avg score = `95.0%`
    *   Balanced Auditor: avg score = `85.0%`
*   **And** the global national average across all completed submissions is `85.0%`
*   **When** a user requests `GET /api/analytics/auditors/productivity`
*   **Then** the response status is `200 OK`
*   **And** the strict auditor has `biasRating = "Strict"` (as avg score is more than 5% lower than national avg)
*   **And** the generous auditor has `biasRating = "Generous"` (as avg score is more than 5% higher than national avg)
*   **And** the balanced auditor has `biasRating = "Balanced"`

## Scenario 4: Auditor Bias Rating Safeguard with Zero Submissions
*   **Given** there are zero completed submissions in the database
*   **When** a user requests `GET /api/analytics/auditors/productivity`
*   **Then** the response status is `200 OK`
*   **And** the returned array is empty (graceful response, no division by zero error)
