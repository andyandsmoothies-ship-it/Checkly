## 1. User Stories & Acceptance Criteria (Gherkin Format)

### Scenario 1: Retrieve Live Filtered Dynamic Data for Province
```gherkin
Given a set of stores in different provinces
And stores have uploaded submissions today
When an Admin requests the boardroom report with query parameter `?province=Hanoi`
Then the endpoint must return HTTP status 200 OK
And the payload must contain `isLiveData = true`
And the averages (score, submissions) must be mathematically calculated *only* for stores in Hanoi
And it must bypass the nightly static snapshot cached averages
```

### Scenario 2: Compute Golden Store Flagship Benchmark
```gherkin
Given a filtered boardroom query is made for `province=Hanoi`
When the report calculates chain metrics
Then the response must contain a `goldenStore` object
And the `goldenStore` must represent the highest-performing flagship store globally across the entire chain in the last 30 days
And the benchmark comparison values must be correct
```

### Scenario 3: Calculate Corrective Action Plan Time-To-Resolution (TTR Velocity)
```gherkin
Given multiple completed submissions with corrective Action Plans in Hanoi
And some Action Plans are closed with a valid `ClosedAt` timestamp
When the Admin queries `?province=Hanoi`
Then the KPI metrics must include `avgTtrDays`
And the TTR must be mathematically calculated in-memory as the average of `(ClosedAt - CreatedAt).TotalDays` only for Hanoi stores
```

### Scenario 4: Return Offline Sync LastSyncedAt for Leaderboard Stores
```gherkin
Given stores have synced their local SQLite databases at various times
When the Admin queries the filtered boardroom report
Then the leaderboard entries (`topStores` / `bottomStores`) must expose the `lastSyncedAt` timestamp
And `lastSyncedAt` must match the persisted value on the `Store` record
```

### Scenario 5: Prevent OLAP Thundering Herd via Server-Side Cache
```gherkin
Given an Admin queries `?province=Hanoi`
When a subsequent request is made for the same parameters within 60 seconds
Then the server must serve the response from `IMemoryCache`
And it must bypass the direct database queries
```
