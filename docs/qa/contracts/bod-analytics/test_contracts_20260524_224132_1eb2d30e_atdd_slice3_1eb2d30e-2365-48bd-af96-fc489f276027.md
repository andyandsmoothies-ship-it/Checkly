# Physical Acceptance Test Contracts - Slice 3
## Topic: Flutter Typed Models & Manager Filter State

```
[UI Component] ────► [BodAnalyticsManager] ────► [BodAnalyticsApiService] ────► [GetBodReport / GetFilteredReport]
                      - isLiveMode: bool          - getReport()
                      - applyFilter()             - getFilteredReport()
                      - clearFilter()
```

## Scenario 1: Parse Fully Typed BodReportResponse from valid JSON (TC-04)
*   **Given** a JSON payload from the server containing `chainKpis`, `trend`, `topStores`, `bottomStores`, `categoryBreakdown`, `apAging`, `auditorProductivity`, and a net-new `goldenStore` object
*   **When** `BodReportResponse.fromJson` is evaluated on the payload
*   **Then** the resulting object contains fully-typed properties:
    *   `chainKpis` has `totalAudits`, `avgScore`, and `avgTtrDays`
    *   `topStores` has items with a typed `DateTime? lastSyncedAt` field
    *   `goldenStore` contains the flagship store `{ storeId, storeName, avgScore }`

## Scenario 2: Parse Gracefully with Null Golden Store (Gap Analysis AC)
*   **Given** a JSON payload where `goldenStore` is explicit `null` and `chainKpis` has default zeroes
*   **When** `BodReportResponse.fromJson` is evaluated on the payload
*   **Then** the `goldenStore` field is parsed as `null` cleanly without crashing

## Scenario 3: Apply Filter Updates Manager State & Calls API
*   **Given** `BodAnalyticsManager` is in its default state (not loading, not live mode)
*   **When** `applyFilter("Hanoi", "Hoan Kiem")` is called
*   **Then** the manager state enters loading
*   **And** `isLiveMode` is set to `true`
*   **And** `activeProvince` is `"Hanoi"` and `activeDistrict` is `"Hoan Kiem"`
*   **And** it calls `MockBodAnalyticsApiService.getFilteredReport("Hanoi", "Hoan Kiem")`

## Scenario 4: Concurrency Guard Ignores Rapid Concurrent Filter Submissions (Gap Analysis AC)
*   **Given** `applyFilter("Hanoi", "Hoan Kiem")` is already in progress and the manager is in loading state
*   **When** another concurrent call to `applyFilter("Hanoi", "Ba Dinh")` is triggered immediately
*   **Then** the second concurrent call is ignored
*   **And** only a single API request is dispatched to `MockBodAnalyticsApiService.getFilteredReport`

## Scenario 5: Calculate 3-month Simple Moving Average (SMA3) for Trend Curve (TC-12)
*   **Given** a series of raw monthly average scores: `[81.0, 83.2, 82.5, 85.0]`
*   **When** the TrendUtils SMA3 calculator is evaluated for index 2 (3rd month)
*   **Then** the computed moving average is `(81.0 + 83.2 + 82.5) / 3 = 82.23%`
*   **And** for index 0 and 1 (fewer than 3 months of history), the raw scores `81.0` and `83.2` are returned gracefully without crash
