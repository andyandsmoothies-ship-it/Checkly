## First Principles Gate

1. **Physics & Limit**: 
   - *C# Compiler Limit*: The C# compiler restricts an assembly to a single entry point (compilation unit with top-level statements). `CheckAuditor.csproj` implicitly compiles all `.cs` files recursively in its folder structure, trying to compile both `DbQuery/Program.cs` and `TemplateCreator/Program.cs` under the same assembly context, violating this limit.
   - *JVM Version Limit*: The host OS is running JDK 25 (`25.0.2`), which exceeds the maximum supported JDK version of the Kotlin Gradle Plugin version `2.2.20` used in the Android project. Kotlin's version parser throws an `IllegalArgumentException` on unrecognized JDK version formats.
2. **Simplicity Check**:
   - The C# compiler is trying to compile two separate runnable programs as one project.
   - Gradle is running on Java 25, which Kotlin doesn't understand.
   - The Dart test has unused imports left over from previous refactorings.
3. **Blast Radius**:
   - Total compilation failure for helper tools under `.agents/tmp/`.
   - Android application builds (e.g. `flutter build apk` or local android runs) are blocked entirely.
   - Linter warnings prevent clean CI gates.
4. **Observability**:

## Root Cause Description

1. **Top-Level statements collision**: `CheckAuditor.csproj` does not exclude the `DbQuery/` and `TemplateCreator/` folders. Because both directories contain `Program.cs` files with top-level statements, compiling the project compiles both files into the same assembly.
2. **DbQuery Syntax/Model Errors**: `DbQuery/Program.cs` has incorrectly escaped quotes (`\"` instead of `"`) in string declarations. It also references the non-existent `Areas` entity and `AreaId` column on `Store`.
3. **JVM version incompatibility**: Gradle runs on the default host JVM (JDK 25) which is incompatible with Gradle's Kotlin compiler plugin.
4. **Unused Imports**: Refactoring of the `UnsavedChangesGuard` test removed usage of `GoRouter`, `StoreFormSheet`, and other imports but did not clean up their declarations.
