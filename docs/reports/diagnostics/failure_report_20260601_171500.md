## Root Cause

1. **Unused Local Variables**: The Flutter UI codebase contained local variables (`subTextCol` in `area_bod_ap_aging_funnel.dart` and `theme` in `metadata_form_card.dart`) that were instantiated but never read, violating the strict `unused_local_variable` linter constraint.
2. **Unnecessary Null Guard Conditions**: Properties (`productivityChip` in `area_bod_auditor_scatter.dart` and `statusChip` in `area_bod_category_weakness.dart`) were marked as nullable (`PillChip?`), yet every conditional code path initialized them. The subsequent `if (chip != null)` checks inside collection literals threw `unnecessary_null_comparison` and `use_null_aware_elements` linter warnings.
3. **Legacy Collection-If Syntax**: In `area_bod_score_trend.dart`, an explicit `if (trajectoryChip != null) trajectoryChip` null-check was flagged under the newer `use_null_aware_elements` rule.
4. **Deprecated APIs**: Widgets (`area_bod_store_detail_sheet.dart` and `bod_store_detail_sheet.dart`) used the legacy `.withOpacity()` method on `Color`, triggering `deprecated_member_use` warnings in the latest Flutter SDK version.
5. **C# Script Collisions**: An external script `CheckAuditor.cs` had been left within the MSBuild project compilation scope, causing class collisions and build failures.
