## Hypotheses & Diagnosis
Hypothesis 2 was correct: The endpoint successfully processes the request but intentionally returns a 401 because the database is empty or credentials are bad.

**Root Cause:**
- The backend `Login.cs` was returning `TypedResults.Unauthorized()` which produces an empty body.
- The Flutter client's `AppError.fromDioException` could not extract the RFC 9457 `code` from the empty body and fell back to `network_error`. 
- This caused the UI to show a generic "We couldn't connect" message, prompting the user to check terminal logs which displayed the raw `DioException` 401 stacktrace.

**Resolution:**
- Modified `Login.cs` to return `TypedResults.Problem(statusCode: 401, extensions: ... "code": "invalid_credentials")` instead of `Unauthorized()`.
- Added `'invalid_credentials'` mapping to the `ErrorDictionary.dart` in Flutter.
- Tests updated and passed successfully.
