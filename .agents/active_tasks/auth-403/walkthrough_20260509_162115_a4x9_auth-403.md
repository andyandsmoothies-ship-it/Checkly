# Walkthrough: Area Manager 403 on Programs

## Description
This walkthrough outlines the changes made to resolve the 403 Forbidden error encountered by Area Managers attempting to sync and execute program assignments.

## Changes Made
1. **PBAC Capabilities Seeded**: 
    - Added `programs:assignments_my` and `programs:execute` capability mappings for the `area_manager` role inside `server/Program.cs`. This explicitly grants Area Managers execution access.
2. **Integration Test Suite Seeded**: 
    - Mirrored the PBAC seeds into `server/tests/Checkly.Api.Tests/TestWebApplicationFactory.cs` to ensure backend integration tests are aligned with production capabilities.
3. **Documentation Updated**: 
    - Removed the stale comment in `server/Features/Programs/SubmitProgramEvidence.cs` that incorrectly stated the endpoint was strictly tied to the `store_manager` role. Updated the comment to explicitly state that the endpoint is governed by the `programs:execute` PBAC capability.

## Verification
- Backend tests for the `Programs` module were run using `rtk dotnet test --filter "FullyQualifiedName~Programs"` and completed successfully.
