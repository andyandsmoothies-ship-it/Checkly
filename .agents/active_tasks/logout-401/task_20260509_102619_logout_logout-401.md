## Hypotheses
1. The auth token is cleared locally *before* the API call to `/notifications` is made.
2. The `/notifications` endpoint itself throws a 401 because the token has already expired on the server.
3. The API client (Dio) is not gracefully handling 401s during the logout sequence, where a 401 is an acceptable response if the token is already invalid.
