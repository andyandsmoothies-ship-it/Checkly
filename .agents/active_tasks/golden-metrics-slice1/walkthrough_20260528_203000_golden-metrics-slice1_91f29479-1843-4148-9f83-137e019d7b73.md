## Gotcha Protocol

Proposed additions/modifications to global gotchas in relevant folders:

### Add to `server/GEMINI.md`:
- **Gotcha: EF Core Left Join Null Template Behavior**:
  - *Description*: When building dynamic queries checking archetype/type properties of standard template-linked entities (e.g. `Submission.Template`), raw filters like `s.Template.Type == "QC"` will drop records where the foreign key `TemplateId` is `null` (since they fail inner/left join conditions).
  - *Fix*: Always write `(s.TemplateId == null || s.Template!.Type == "QC")` to explicitly handle legacy fallback submissions while safely filtering archetypes in child templates.
