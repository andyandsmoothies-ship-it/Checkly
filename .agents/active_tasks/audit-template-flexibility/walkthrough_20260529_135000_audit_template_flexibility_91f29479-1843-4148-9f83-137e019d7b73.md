## ## Decision Log

### A. Stateless layout validation (`DartTemplateLinter`)
The linter executes layout checking rules dynamically in real time:
- **`EmptyStructureCheck`** (Blocking Error): Fails if the builder payload is completely empty.
- **`EmptySectionName`** (Blocking Error): Fails if any section has an empty or blank title.
- **`PenaltyModeGroupSum`** (Blocking Error): Fails in penalty scoring mode if weight sum != 100.
- **`DuplicateIdCheck`** (Blocking Error): Fails if identical GUIDs exist in layout nodes.
- **`MaxNestingDepthExceeded`** (Blocking Error): Fails if group depth > 2.
- **`MixedAuditWarning`** (Warning): Warns if scored and unscored criteria are mixed.
- **`SilentRiskInSurvey`** (Warning): Warns of risk points inside non-scoring survey templates.
- **`ProgressiveZeroImpact`** (Warning): Warns if progressive penalty is enabled with zero impact.

### B. Adaptive UI components (`TemplateLinterPanel`)
The panel rendering is adapted directly from Duolingo reskin principles:
- Employs `StrokeCard` and `PillChip` style widgets for aesthetic consistency.
- Responsively switches presentation layouts:
  - **Desktop (Width >= 800px)**: Side-by-side split row panel in the builder.
  - **Mobile (Width < 800px)**: Bottom sheets/tabs to fit small viewports.
- Tapping an alert scrolls the target widget directly into view via `Scrollable.ensureVisible`.
