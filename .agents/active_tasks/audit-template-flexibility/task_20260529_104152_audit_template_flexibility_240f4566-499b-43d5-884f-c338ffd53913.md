    - `EmptySectionName` (blank/whitespace group title)
    - `PenaltyModeGroupSum` (sum of group weights must be exactly 100 in penalty mode if specified)
    - `DuplicateIdCheck` (no duplicate GUID keys anywhere in the tree structure)
    - `MaxNestingDepthExceeded` (nesting depth cannot exceed 2 levels, i.e., Group -> Child group, no deeper nesting)
    - `PoisonPillPayloadLimit` (reject tree payloads containing >500 total elements with 400 Bad Request)
    - `TenantOwnershipCheck` (enforce that the authenticated user's Tenant/Company owns the template being modified with 403 Forbidden)
  - **Advisory Rules (200 with warnings):**
    - `MixedAuditWarning` (mixed scored criteria and unscored comment/text inputs in a template)
    - `SilentRiskInSurvey` (criteria with `IsRisk = true` in a survey-type template)
    - `ProgressiveZeroImpact` (progressive repeats enabled with `MinusImpact = 0` or negative values)
