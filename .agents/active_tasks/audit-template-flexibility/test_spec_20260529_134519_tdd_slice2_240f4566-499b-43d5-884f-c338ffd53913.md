## 1. Test Strategy Overview

We are testing the implementation of the stateless `DartTemplateLinter` and the visual `TemplateLinterPanel` widget following strict Detroit-style unit and widget testing.

### Component Design Under Test

1. **`DartTemplateLinter`**:
   - Static stateless function `TemplateLintResult run(List<EditableGroup> sections, String templateType, String scoringLogicConfig)`
   - Computes:
     - `EmptyStructureCheck` (Blocking)
     - `EmptySectionName` (Blocking)
     - `PenaltyModeGroupSum` (Blocking)
     - `DuplicateIdCheck` (Blocking)
     - `MaxNestingDepthExceeded` (Blocking)
     - `MixedAuditWarning` (Advisory)
     - `SilentRiskInSurvey` (Advisory)
     - `ProgressiveZeroImpact` (Advisory)
   - Exposes model representations matching the backend `LintResult` & `LintIssue` JSON.

2. **`TemplateLinterPanel`**:
   - Widget that accepts `TemplateLintResult` and a callback `onScrollToTarget(String targetId)`.
   - Renders red error alerts for `Error` severity and yellow warning cards for `Warning` severity.
   - Shrinks to `SizedBox.shrink()` (zero height) when there are no issues.
   - Text wraps elegantly using `Expanded`/`Flexible` widgets inside `Row` layout cells to prevent layout overflows.

3. **`TemplateBuilderPage` Integration**:
   - Handled asynchronously via debounced (800ms) execution of the `DartTemplateLinter`.
   - Disables save button on footer if `errors.isNotEmpty` is true.
   - Displays a bypass checkbox and dynamic info toast for advisory warnings.
   - Binds and binds HTTP 422 backend validation response bodies containing custom linter payload issues directly back to the visual linter panel on save attempt.

## 2. Test Cases Draft

### `DartTemplateLinter` Unit Tests
1. **`DartTemplateLinter_EmptyStructure_FiresError`**:
   - **Input**: Empty section list `[]`.
   - **Assertion**: Returns 1 blocking error for `EmptyStructureCheck`.
2. **`DartTemplateLinter_EmptySectionName_FiresError`**:
   - **Input**: Section with whitespace or null title.
   - **Assertion**: Returns 1 blocking error for `EmptySectionName` targeting that section's temporary/real ID.
3. **`DartTemplateLinter_PenaltyModeGroupSum_FiresError`**:
   - **Input**: `scoringMode: 'penalty'`, total weights sum to 95%.
   - **Assertion**: Returns 1 blocking error for `PenaltyModeGroupSum`.
4. **`DartTemplateLinter_DuplicateIdCheck_FiresError`**:
   - **Input**: Two criteria or groups sharing the same Guid string.
   - **Assertion**: Returns 1 blocking error for `DuplicateIdCheck`.
5. **`DartTemplateLinter_MaxNestingDepthExceeded_FiresError`**:
   - **Input**: Groups nested 3 levels deep (Group -> Subsection -> Subsubsection).
   - **Assertion**: Returns 1 blocking error for `MaxNestingDepthExceeded`.
6. **`DartTemplateLinter_MixedAuditWarning_FiresWarning`**:
   - **Input**: Scored criterion (pointsWeight = 10) beside unscored text criterion.
   - **Assertion**: Returns 1 advisory warning for `MixedAuditWarning`.
7. **`DartTemplateLinter_SilentRiskInSurvey_FiresWarning`**:
   - **Input**: `templateType: 'survey'`, criterion with `isRisk = true`.
   - **Assertion**: Returns 1 advisory warning for `SilentRiskInSurvey`.
8. **`DartTemplateLinter_ProgressiveZeroImpact_FiresWarning`**:
   - **Input**: `progressiveRepeat: true`, criterion with `minusImpact = 0` or weight `0`.
   - **Assertion**: Returns 1 advisory warning for `ProgressiveZeroImpact`.

### `TemplateLinterPanel` Widget Tests
9. **`TemplateLinterPanel_EmptyResult_RendersZeroHeight`**:
   - **Arrange**: Pass a `TemplateLintResult` with no errors and no warnings.
   - **Assert**: Verify that nothing is rendered (zero size or no matching widgets).
10. **`TemplateLinterPanel_RendersErrorsAndWarnings`**:
    - **Arrange**: Pass a `TemplateLintResult` containing 1 error and 1 warning.
    - **Assert**: Verify that cards containing the exact warning and error texts are found.
11. **`TemplateLinterPanel_TapIssueCard_CallsOnScrollToTarget`**:
    - **Arrange**: Render panel with 1 error card containing `targetId: "target-id-123"`.
    - **Act**: Tap the card.
    - **Assert**: Callback `onScrollToTarget` is invoked with `"target-id-123"`.
12. **`TemplateLinterPanel_TextWrapping_NoOverflow`**:
    - **Arrange**: Render with exceptionally long message string.
    - **Assert**: Verify no layout rendering constraints overflow warnings are printed or thrown in headless environment.

### `TemplateBuilderPage` Integration & Controller Tests
13. **`TemplateBuilderPage_DebouncedLinter_ExecutesAndCancels`**:
    - **Act**: Simulate typing into Title/Section text fields repeatedly.
    - **Assert**: The linter runs exactly once after 800ms. Disposing page cleans up timer.
14. **`TemplateBuilderPage_DisableSaveOnError`**:
    - **Arrange**: Builder state has a blocking error.
    - **Assert**: Verify the bottom footer save/publish button is visually disabled or inactive.
15. **`TemplateBuilderPage_HandleBackend422Responses`**:
    - **Arrange**: Mock `TemplateManager.saveTemplate` throwing a `DioException` of type `422 Unprocessable Entity` with a structured `LintResult` response body.
    - **Act**: Click save/publish with bypass checkbox.
    - **Assert**: The thrown errors are successfully bound and displayed inside the linter panel.
