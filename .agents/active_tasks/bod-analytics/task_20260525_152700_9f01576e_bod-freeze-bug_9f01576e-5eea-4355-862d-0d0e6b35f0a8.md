## Root Cause
`BodApBucketDetailSheet.initState()` (line 29) calls `widget.manager.loadApDetails()` DIRECTLY —
WITHOUT wrapping it in `WidgetsBinding.instance.addPostFrameCallback()`.

`loadApDetails()` calls `notifyListeners()` synchronously before returning to the event loop.
This fires a rebuild of `AnimatedBuilder` while Flutter is still building the initial widget tree.
Flutter throws: "setState() or markNeedsBuild() called during build."

`BodCategoryDetailSheet` and `BodStoreDetailSheet` are correctly implemented using `addPostFrameCallback`.
`BodApBucketDetailSheet` is missing that guard.

## Hypotheses
1. `BodApBucketDetailSheet.initState()` does NOT use `addPostFrameCallback` → CONFIRMED
2. The `notifyListeners()` in loadApDetails triggers rebuild mid-frame → CONFIRMED
