## ## Decision Log

### 1. The Issue
- **Bug**: Bottom sheets (`BodStoreDetailSheet`, `BodCategoryDetailSheet`, `BodAuditorDetailSheet`) were synchronously invoking state load triggers (e.g. `loadStoreDetail`) in their `initState()` methods.
- **Root Cause**: These state load methods trigger `notifyListeners()` synchronously inside `BodAnalyticsManager`. Because this happens during the bottom sheet mounting/build pipeline, the parent `ListenableBuilder` / `AnimatedBuilder` received a rebuild trigger during the middle of the frame layout, causing the fatal:
  `FlutterError (setState() or markNeedsBuild() called during build.)`

### 2. Resolution Path
- **Implementation**: Defer the state updates to the post-frame callback by using:
  ```dart
  WidgetsBinding.instance.addPostFrameCallback((_) {
    if (mounted) {
      widget.manager.load...();
    }
  });
  ```
- **Result**: State loading is scheduled cleanly for the next frame right after the current frame is mounted, completely preventing build-phase notification collisions.

## ## Gotcha Protocol

- **Synchronous Notification Prevention**: Stateful widgets that mount as sheets or modals must defer any synchronous listener notification triggers (e.g. methods calling `notifyListeners()`) inside `initState` using `WidgetsBinding.instance.addPostFrameCallback`. This ensures perfect coordination with the Flutter render loop.
